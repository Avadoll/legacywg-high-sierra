При отсутствии подтверждения окно остаётся открытым с ошибкой. Продолжение туннеля после Quit пока не реализовано и не предлагается.

## Повторный импорт и диалоги профиля

Импорт сначала bounded-read/strict worker validation, затем private Keychain comparison без публичных hashes. Повтор определяется по Unicode-normalized case-insensitive имени либо точным bytes существующей конфигурации. Semantic equivalence после изменения comments/whitespace не вычисляется. При нескольких совпадениях explicit picker выбирает конкретный ID; «Заменить выбранный» обновляет только kSecValueData одного item, сохраняя его имя/ID и не выполняя delete/add. «С новым именем…» сохраняет отдельный ID после проверки свободного имени. Отмена не вызывает commit. Исходный .conf только читается. Лимиты: 256KiB, имя1–80 без control/bidi, до128 профилей для bounded duplicate comparison; больший legacy set требует уменьшения перед импортом. Unreadable/locked Keychain не трактуется как отсутствие записи.

Отдельный interactionPending блокирует пользовательские connect/disconnect/recovery/profile actions и Quit на время sheet/validation/Keychain work, но не блокирует status request path/common-mode timer. Validation/file/secret reads и commits выполняются вне main thread. Delete/replace требуют подтверждённого inactive state и повторно проверяют его при подтверждении; unknown/RecoveryRequired/Connecting/Connected отказываются. Rename допускается при active tunnel, меняет только label. Quit dialogs тоже ставят interaction guard; alert/copy/save cancellation освобождает его.

## Сведения о выбранном профиле / лицензии

В главном окне теперь отдельно показаны выбранный профиль (routing/local addresses/peer endpoints) и runtime statistics активного профиля. Selection читает Keychain и запускает --validate вне main thread, в serial preview queue; generation проверяется перед работой и при ответе, устаревший результат не подменяет новый выбор. Reload/import/replace/rename явно обновляют preview даже при прежнем row index. Пока профиль не подтверждён, Connect недоступен; неподдерживаемый профиль показывает фиксированное русское объяснение. Status/heartbeat path не ждёт preview queue.

Worker validation возвращает только пять private metadata fields: routing, addresses, address_count, endpoints, route_count. Address preview≤8/total count≤2048, endpoints≤16 (включая empty sentinel для отсутствующего Endpoint). Main text сокращает addresses/endpoints, tooltip содержит bounded полный preview. Routing использует тот же NetworkCore coverage algorithm, что CheckCapabilities: fragmented /1 defaults считаются full. Нет DNS lookup/utun/route/PF mutation при validation; публичный Status и diagnostic allowlist не расширены metadata. Go tests проверяют отсутствие actual private/public/PSK values, unchanged session, full dual-stack classification и response≤8KiB для1024 addresses/16 maximum-length hostnames. Semantic limits не объявляют такой большой профиль исполнимым.

«О программе и лицензии…» открывается из главного меню. Показаны version, independent/research status, THIRD_PARTY_NOTICES и десять фиксированных bundled license/patent files. Read≤128KiB/file, total≤1MiB, plain selectable text; нет remote load. Отсутствующий/невалидный файл — фиксированная ошибка. Own-code license явно остаётся undecided. About sheet использует interaction guard и не объявляет High Sierra/protection confirmed.
