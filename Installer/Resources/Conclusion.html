Следующие шаги

Откройте LegacyWG в папке «Программы», импортируйте свой файл .conf и нажмите «Подключить».

Для полного туннеля в профиле должны быть один сервер, Endpoint, DNS и маршрут 0.0.0.0/0. Для передачи IPv6 через сервер также нужны IPv6-адрес и маршрут ::/0.

Успешная установка ещё не подтверждает соединение с вашим сервером. После подключения проверьте наличие handshake и передачу данных в приложении.

Перед закрытием приложения нажмите «Отключить». Тестовая версия не обеспечивает постоянную блокировку обычной сети при обрыве VPN.

Для удаления отключите VPN, закройте LegacyWG и откройте прилагаемый пакет LegacyWG-remove-test-0.2.pkg. Он удаляет только компоненты этой сборки. Сохранённые профили в связке ключей остаются у пользователя.
