# Изменение пути до endpoint

Worker читает фактический маршрут к каждому выбранному числовому endpoint через BSD routing socket (`RTM_GET`). Исходное состояние фиксируется до создания utun, повторно проверяется после адресов/routes/DNS и затем каждые две секунды. Один общий deadline на набор адресов — две секунды; максимум 16 endpoints, одинаковые IP дедуплицируются. У socket короткие read/write timeouts; число чужих сообщений и размер ответа ограничены. Нет shell, разбора локализованного route output, полного dump сети или адресов в argv/logs/public DTO.

Сравниваются interface index/name, direct/gateway routing, gateway scope и исходный IP/scope, если kernel возвращает его. Unavailable/reject/blackhole/dead routes не принимаются. ARP/NDP hardware address не является идентичностью пути. При изменении или невозможности проверки закрывается engine/utun и own temporary DNS; статус становится Error с фиксированным сообщением без адресов. Stop завершает monitor и observer; старый observer не закрывает новую session.

Это консервативное закрытие split session с bounded polling, не fail-closed политика. Между checks есть интервал; обычный split трафик вне AllowedIPs продолжает пользоваться исходной сетью. Не реализованы auto reconnect/backoff, полноценный sleep/wake, DNS re-resolution, captive portal или физические host escape routes. ## Текущие endpoints в production worker

Run38464390218/source`583c17f476858d22e8361fc0a809371b849a48a0`: Intel macOS15.7.9/Xcode16.4 build/tests/vet и native helper/IPv4/IPv6/dual-stack/multi-peer/DNS/20cycles/route-loss/GUI lifecycle/recovery/research installer PASS. Source/artifact/app/pkg hashes подтверждены.

После установки сети тот же двухсекундный monitor теперь читает private official IpcGet и выбирает только configured peer identities в исходном порядке. Snapshot ограничен128KiB,16peers и4096bytes/line; unknown/duplicate/missing peers, повторные endpoint поля, hostname/zone/mapped/unspecified/multicast/zero-port значения отвергаются. Endpoints, keys/UAPI и route identities не добавлены в public DTO, journal, argv, logs или diagnostics.

Для каждого текущего peer IP проверяются отсутствие пересечения с AllowedIPs/собственными адресами, usable kernel path и отличие от собственного utun. Сравнивается исходная path identity конкретного peer (index/name/direct/gateway/source/scope); новый numeric IP/port с тем же путём может продолжать работу. Каждый poll проверяет именно новый IP, поэтому дальнейшее изменение его отдельного маршрута уже не скрыто исходным profile endpoint. Совпадающие IP дедуплицируются. Passive peer без начального endpoint получает private baseline после появления endpoint в official state и успешной проверки вне tunnel routes. Между polls нет накопления адресов: один baseline/peer и максимум16queries/cycle. Config destruction не затрагивает скопированные prefixes/indices/initial endpoints.

Unit fixtures подтвердили peer reorder, malformed/foreign/missing/oversized metadata, same-path roaming и последующее попадание нового IP в собственный utun, overlap refusal до kernel query, gateway/source changes, shared-IP deduplication, passive baseline, cancellation и fixed errors. Native Darwin test подтвердил RTM_GET к новому loopback destination. Реальные длительные helper/GUI encrypted sessions используют новый sampler. Controlled native IPv4 e2e с настоящим helper теперь прошёл run38468237984, ниже. Аналогичный IPv6/dual-stack и physical network e2e ещё требуются; developer scoped roaming proof не заменяет их.

Native routing queries теперь используют unique positive process sequence вместо постоянного Seq1; exhaustion отвергается. Default Bind и unscoped route lookup остаются прежними. Это post-observation conservative split shutdown; первые пакеты после roaming могут предшествовать poll. Deadline проверяется до/после IpcGet и общий для kernel queries, но library IpcGet не имеет принудительной отмены. Нет packet-level guard, auto reconnect, dynamic owned PF exceptions или full tunnel. Cross-family/new-gateway/source/interface path changes консервативно прекращают session до реализации проверенного reconnect. Physical/DHCP/index-generation/sleep/High Sierra остаются open.
